/ about_chaoslab

Practice incident response before it becomes an incident.

ChaosLab is a seeded cybersecurity incident simulator for learning how to investigate suspicious activity in server logs.

01 / THE IDEA

Learn by investigating

Each mission places you inside a simulated server environment. Read the evidence, follow patterns in the logs, identify the attackers and explain what they did.

02 / THE EXPERIENCE

From solo to classroom

ChaosLab supports singleplayer practice, multiplayer races and institution classrooms, so learners can build confidence independently or work together.

03 / THE PURPOSE

Make security skills practical

The project turns abstract security concepts into repeatable, measurable exercises with seeded scenarios, difficulty levels and saved results.

>

Whether you are learning the fundamentals of log analysis or testing your response speed, ChaosLab gives you a safe place to investigate.
